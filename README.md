# PlotProof

Check chart colors against their background, repair weak colors, and preview in grayscale.

- [Download the offline prototype and source](./PlotProof-build-and-source.zip). Extract the archive and open `dist/PlotProof.html` in a modern browser.
- [Watch the captioned 53-second demo](./PlotProof-demo.mp4).

The sample chart uses synthetic data. Start with the default palette, choose **Fix low contrast**, then switch to **Grayscale**. The checker measures bar fills against the plot background using the WCAG 2.2 relative-luminance contrast formula. It helps with palette review. Review the complete figure separately.

Prepared for Silicon Valley Buildathon with OpenAI Codex assistance.
